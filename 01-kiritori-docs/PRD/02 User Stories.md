
## Create note

**Allow the user to create a note**

- Initially, I imagined that it should not be possible for a user to create a note without first finding the connection for it. 
- Since, this is not a simple note taking application. It emphasises the meaning of connection making. 
- So connections are first class citizens, alongside notes and their contents. 
- So it should be impossible to make a note without also connecting it to the existing forest.

## Organise notes 

**Allow the user to review their notes, and organise them as easily as possible**

- User imports some notes
- Imported notes exist outside of collections
- User can review notes which **exist outside of collections**, and organise them by easily editing the collections field for each note
